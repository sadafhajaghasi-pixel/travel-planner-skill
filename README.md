# Travel Planner Skill

A Claude skill that plans trips in my personal travel style: under $5,000, economy flights, clean 4-star+ central hotels, nature + culture destinations (preferably tropical), and relaxed day-by-day itineraries.

## Install

Copy the `travel-planner` folder into your Claude skills directory:

```sh
cp -r travel-planner ~/.claude/skills/
```

Then ask Claude to plan a trip.
